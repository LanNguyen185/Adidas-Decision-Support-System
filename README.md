# Adidas Decision Support System (DSS)

## Overview
This project focuses on building a Decision Support System (DSS) for Adidas business analysis using Excel, Power BI, and AI chatbot integration.

The system supports KPI monitoring, sales analysis, and business decision-making through dashboard visualization and contextual data querying.
